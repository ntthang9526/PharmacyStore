CHAY WEBSITE PHARMACY TREN WINDOWS

1. Cai .NET SDK 8, SQL Server va SSMS (hoac sqlcmd).
   Lay ca thu muc PharmacyStore, khong chi lay rieng Store.Web.

2. Chuan bi database PharmacyStoreDB:
   - Neu duoc giao file .bak: Restore trong SSMS, dung SQL Server tuong thich
     voi phien ban tao backup. Khong ghi de database dang co du lieu can giu.
   - Neu cai moi: mo Store.DAL/Database/InitDatabase.sql trong SSMS,
     ket noi SQL Server local va nhan F5 chay TOAN BO file mot lan.
     Khong can bat SQLCMD Mode. File tu tao PharmacyStoreDB, cau truc POS
     va web, 123 thuoc, 12 nhom, 18 NCC, 27 khach hang, 124 lo,
     130 hoa don POS, 25 phieu nhap, 16 voucher va 1 don web mau.
     Chi tao moi; neu PharmacyStoreDB da ton tai, script dung de tranh
     ghi de. Khong xoa database cu neu chua sao luu du lieu can giu.

3. Sau InitDatabase.sql KHONG can chay them cac script tich hop/catalog/ton kho.
   Du lieu la ban mau cho bai tap; thong tin lien he da duoc thay the.
   Khong sao chep tai khoan web cu. Khach hang web tu dang ky moi.
   POS mau: admin / PharmacyPos!2026. Doi mat khau neu dung ngoai bai tap.
   Neu dung sqlcmd: sqlcmd -S ".\SQLEXPRESS" -E -C -b -f 65001 -i ".\Store.DAL\Database\InitDatabase.sql"
   Du an chi giu InitDatabase.sql. Database cu thieu cau truc can duoc sao
   luu va nang cap rieng; khong chay init de thay the du lieu dang su dung.

4. O thu muc goc, copy .env.example thanh .env.
   Sua DB_SERVER theo ten server dung de ket noi SSMS.
   Mac dinh: .\SQLEXPRESS, Windows Authentication, PharmacyStoreDB.
   Khong can mat khau SQL khi DB_INTEGRATED_SECURITY=true.

5. Neu database chua co Admin web:
   Copy Store.Web/.env.web.example thanh Store.Web/.env.web.
   Dien mat khau rieng vao WEB_ADMIN_PASSWORD.
   File nay chi tao Admin lan dau, khong doi mat khau tai khoan da ton tai.
   Neu restore database da co Admin: dung tai khoan duoc nhom giao rieng.
   Tai khoan POS va tai khoan website la hai he thong dang nhap rieng.

6. Mo PowerShell tai thu muc goc du an, chay:
   dotnet restore .\Store.Web\Store.Web.csproj
   dotnet dev-certs https --trust
   dotnet run --project .\Store.Web\Store.Web.csproj --launch-profile Store.Web

7. Mo https://localhost:55441
   Dang nhap: /Account/Login. Quan tri: /Admin.
   Khach hang co the tu dang ky tai /Account/Register.
   Nhan Ctrl+C trong PowerShell de dung website.

Moi may dung database local rieng. Git pull khong tu dong cap nhat database.
Khong dua .env, .env.web, mat khau hoac file backup len GitHub.
